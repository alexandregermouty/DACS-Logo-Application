# Examples

Fictional files, for trying the tool and for testing. None of these requests is real.

- `example-workspace.json` - a Secretariat workspace with five invented requests (open it with *Continue from a workspace file*).
- `example-review-pack-WG1.json` - a review pack for WG1 (open it with *Open a review pack*).
- `example-response-WG1.json` - the response a WG1 lead would return (import it as Secretariat, in *Review packs & files → Import responses*).
